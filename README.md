# Study Platform

A modular study platform with authentication, timers, tracking features, and UI components for productivity and focus.

## Features
- Authentication system (login/signup)
- Daily streak tracking
- Dark mode UI
- Focus mode
- Timer system
- Progress tracking
- Notifications system
- Profile updates
- Display stats
- Table filtering
- Sound alerts
